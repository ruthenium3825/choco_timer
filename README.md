# チョコットタイマー v1.2.0

チョコットランド用の非公式軽量オーバーレイタイマーです。  
ゲーム画面上にタイマーやカウンターを重ねて表示し、戦闘や周回時の時間管理を補助します。
<br>
<br>

---

## 💡 主な機能

- **タイマー機能**:  
  設定した時間をカウントダウン表示し、戦闘・周回・バフ管理などに利用できます。

- **複数タイマー管理**:  
  複数のタイマーを同時に保持でき、異なる時間管理をまとめて行えます。

- **ストップウォッチ・ラップ機能**:
  0秒のプリセットを選ぶと、`00:00` からの経過時間を計測できます。タイマーと同時に使用でき、ラップの区間時間も記録できます。

- **カウンター機能**:  
  ホットキー操作で2つのカウンターを増減・リセットでき、討伐数や周回数の記録に使用できます。

- **最前面オーバーレイ表示**:  
  ゲーム画面上へタイマーを重ねて表示し、プレイ中でも確認できます。

- **ホットキー操作**:  
  タイマー開始・リセット・カウンター操作などをキーボードから直接実行できます。キー割り当て変更にも対応しています。

- **自動タイマースタート**:  
  画面上の特定アイコンを検出すると、自動でタイマーを開始できます。

- **システムトレイ常駐**:  
  システムトレイから設定変更や終了操作を行えます。

- **マネキン切替**:
  ゲーム内のAvatarウィンドウを検出すると、下部の「アバター更新」の右側にマネキン選択と「着替え保存」を表示します。Puretomoに保存したマネキンへ、オーバーレイから着替えられます。

## 🛠️ 使い方

### 1. 基本操作
1. アプリ起動後、ゲーム画面をアクティブにすると自動連動します。
2. ゲーム中に **`T` キー** を押すと、選択したプリセット時間のタイマーを開始します。**0秒** を選択している場合はストップウォッチの計測を開始し、計測中はラップを記録します。
3. **`R` キー** を押すと、リセットカーソルで選択されているタイマー・ストップウォッチを消去します。
4. **`.` キー** / **`,` キー** でタイマーの時間を選択できます。
5. アプリを終了する場合は、システムトレイからアイコンを**右クリック**し「終了」を押してください。（ゲームが起動されていない場合、5分経過で自動的に終了します）
<br>

* **配置**: ゲーム画面の位置やサイズに自動で追従します。ゲームを最小化、非アクティブ状態にしている間は自動的に非表示になります。
* **自動タイマースタート**: 特殊羽を使用した際に効果時間に合ったタイマーが自動で開始されます。同アイコンの移行（リア→リエなど）は検出できないため、効果時間終了後（アイコン消滅後）か `R` キー でタイマーを消去してリセットしてください。
* **タイピングモード**: `Enter` キーを押してタイピングモードになると、画面にキーボードアイコンが表示されて文字入力中の誤作動防止のためにホットキーが一時無効化されます。文字入力が終わったら左クリックすると通常モードに戻ります。
* **ストップウォッチ**: `.` / `,` キーでプリセットを **0秒** に合わせ、`T` キーで計測を開始します。0秒を選択したまま再度 `T` キーを押すと、直前のラップ（初回は計測開始）からの区間時間を記録し、経過時間の右側へ左から記録順に表示します。秒単位の表示で、計測自体は継続します。
* **設定の自動保存**: 変更した秒数やキーは同じフォルダ内の `config.json` に自動保存されます。アプリ（.exe）を移動する際は、このファイルも一緒に移動してください。アプリ更新時は`config.json`と同じ場所に置くだけで設定を引き継げます。

### 2. 初期ショートカットキー一覧
ゲームをプレイしたまま、以下のキーで操作できます。

| 操作内容 | デフォルトキー | 説明 |
| :--- | :--- | :--- |
| **タイマー追加／ストップウォッチ開始・ラップ** | `T` | プリセットの選択が0秒以外はタイマーを追加します（最大8個）。0秒ではストップウォッチを開始し、計測中はラップを記録します。 |
| **時間設定（進む/戻る）** | `.` (ピリオド) / `,` (カンマ) | 追加するタイマーの時間を切り替えます（画面に予告表示されます）。 |
| **リセットカーソル移動** | `Tab` | 消去したいタイマー・ストップウォッチを選択するカーソルを表示順に移動します。 |
| **選択中のタイマー消去** | `R` | カーソルが指しているタイマーを個別で1つ消去します。ストップウォッチを選択した場合は計測とラップを消去します。 |
| **全タイマーリセット** | `Ctrl + R` | すべてのタイマーとストップウォッチを一括で消去します。 |
| **カウンター1 [+1 / -1]** | `Z` / `Shift + Z` | 1つ目のカウンターを増減します。 |
| **カウンター1 リセット** | `Ctrl + Z` | 1つ目のカウンター数値を `0` にリセットします。 |
| **カウンター2 [+1 / -1]** | `X` / `Shift + X` | 2つ目のカウンターを増減します。 |
| **カウンター2 リセット** | `Ctrl + X` | 2つ目のカウンター数値を `0` にリセットします。 |
| **マネキン選択（戻る / 進む）** | `Ctrl + ,` / `Ctrl + .` | アバター操作パネルの表示中、前後のマネキンを選択します。 |
| **マネキンの着替え保存** | `F` | アバター操作パネルの表示中、選択中のマネキンをバックグラウンドで保存します。 |

### 3. 設定の変更方法
画面右下のシステムトレイにある「チョコットタイマー」のアイコンを**右クリック**すると、メニューから以下のカスタマイズが可能です。

* **ショートカットキー設定**: 各機能の割り当てキーを自由に変更できます。
* **タイマープリセット編集**: `T`キーで呼び出す時間を0〜5999秒で編集・追加できます。初期プリセットは **300・600・1800・3600・0秒** の順で、0秒はストップウォッチ用です。
* **表示サイズ・位置変更**: UI表示サイズを「標準」「大」、表示位置を「標準(上)」「やや下」から選べます。
* **各種機能のオン/オフ**: カウンター機能や効果音のON/OFF、効果音の音量調整（0〜100%）などがいつでも変更可能です。

## 👗 マネキン切替の使い方

1. ゲーム内でAvatarウィンドウを開きます。左上の「Avatar」の文字を検出し、下部の「アバター更新」の右側にプルダウンと保存ボタンを表示します。
2. プルダウンの「マネキン一覧を取得」を押すか、トレイの「クローゼット連携」→「ログイン／一覧を更新...」を選びます。
3. 初回は専用のPuretomo画面で、ご自身のハンゲアカウントにログインしてください。普段のブラウザーとは別のログイン状態です。ログイン後に一覧を取得すると、専用画面は自動で非表示になります。
4. プルダウン、または `Ctrl + ,` / `Ctrl + .` でマネキンを選び、「着替え保存」ボタンまたは `F` キーで保存します。キー操作はゲームがアクティブで操作パネルが表示されている間だけ有効です。タイピングモード中・ショートカット無効時は動作しません。選択だけでは保存しません。複数ページのマネキンを取得し、未保存の空き枠は一覧から除外します。
5. ボタンの「保存完了」を確認してから、ゲーム側の「アバター更新」を押してゲームへ反映します。失敗した場合は「処理失敗」と表示します。ログイン後の保存はバックグラウンドで行います。

- 一覧を変更した場合は、プルダウンの「一覧を更新...」から再取得できます。「クローゼットを開く...」で専用画面を再表示できます。
- Avatarウィンドウの移動に追従します。
- ゲーム画面を最大化中は操作パネルのクリックを無効にして、ゲームへフォーカスを維持します。（非アクティブ状態になると自動で最大化が解除されてしまうため）事前にログイン・一覧の取得を済ませ、`Ctrl + ,` / `Ctrl + .` と `F` で操作してください。通常のウィンドウ表示ではマウス操作も可能です。キーはトレイの「ショートカットキー設定」から変更でき、設定を保存します。
- 着用できないアイテムがある場合は保存しません。通信結果が不明な場合は自動で再保存しません。クローゼットで状態を確認してください。
- 専用画面の「×」は画面を非表示にし、アプリの終了までログイン用のセッションを維持します。ログイン期限が切れた場合は、トレイの「ログイン／一覧を更新...」から再ログインしてください。
- ログイン状態は専用ブラウザーのプロファイル（`%LOCALAPPDATA%\ChocoTimer\ClosetProfile`）に保持します。パスワードやCookieを `config.json` に保存することはありません。
- 専用ブラウザーのプロファイルにはログイン状態が含まれるため、他人への共有や配布ファイルへの同梱はしないでください。
- トレイの「クローゼット連携」→「マネキン切替を有効」でON/OFFを変更できます。検出されていない場合や、ゲームが非アクティブ・最小化中の場合は操作パネルを表示しません。
- Puretomo側の仕様変更やログイン期限切れにより、連携できなくなる場合があります。既存のタイマー・カウンター機能はクローゼットへのログインなしで使用できます。
